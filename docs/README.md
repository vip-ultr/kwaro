# kwaro Documentation

This folder is the source of truth for kwaro's plan, architecture, and decisions.
Everything is documented here before implementation, so the project stays coherent
as it grows.

## Contents

- `vision.md` — what kwaro is, who it's for, and the principles behind it.
- `architecture.md` — how the pieces fit together (engine, providers, analyzers, UI).
- `providers.md` — the model provider strategy (free-first, bring-your-own-key).
- `ui.md` — the terminal and browser UI design direction.
- `roadmap.md` — phased build plan.

## How to read this

Start with `vision.md`, then `architecture.md`. Each document is a living plan:
update it as decisions change.
